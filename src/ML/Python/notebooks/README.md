# Frozen: the 20-year analysis report

`final_report.ipynb` is the 20-year rewrite of the course report (v0.25 era, schema v3,
five-model zoo, gated/scalarized 2×2). It is kept as a **historical record** and is no longer
executed: its builder (`scripts/build_report_notebook.py`), helpers, and the `report`
command were retired in the pre-v0.3 downsizing (`DataMemo/archive/RetiredComponents.md` §7)
and are recoverable from the tag `archive/v0.3-pre-downsize`.
